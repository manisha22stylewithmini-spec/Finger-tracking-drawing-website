# Air Draw

Draw in the air with your index finger. Hand tracking runs in the browser (MediaPipe) and the camera video never leaves your device.

- ☝️ Index finger: draw
- ✌️ Two fingers: move the pen / hover a toolbar button to press it
- 🖐️ Open palm: erase
- ✊ Fist: pause

Static site, no build step. Serve over HTTPS (or localhost) so the browser allows camera access.
